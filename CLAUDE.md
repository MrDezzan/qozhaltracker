# QozhalTracker
## Поиск готовых skills (стандартный шаг)
Перед новой задачей проверяй, нет ли подходящего skill на https://skills.sh (skill `find-skills`, `npx skills find <запрос>`).
Если подходящий есть:
1. Проверь надёжность источника (официальный вендор/известная организация, число установок, репозиторий на GitHub).
2. Кратко объясни, что он делает.
3. Предложи установить.
4. Без подтверждения пользователя ничего не устанавливай.
